ВАЖНО: файлы index.html, которые находятся в архиве до запуска клонирования, — предыдущая приблизительная реконструкция, а не подтверждённая копия 1:1.

Чтобы получить точную локальную копию исходных страниц и их реальных файлов на компьютере с доступом к интернету:

1. Распакуйте весь архив в отдельную папку.
2. Убедитесь, что установлен Python 3 (команда py в Windows).
3. Дважды щёлкните run-clone.bat.
4. Скрипт загрузит исходный HTML страниц, обнаруженные изображения, CSS, JavaScript, шрифты и другие статические ресурсы; ссылки на скачанные ресурсы будут заменены локальными путями.
5. Откройте site-1/index.html или site-2/index.html.
6. Если часть ресурсов не загрузилась, посмотрите clone_report.txt.

Источники:
- https://dexxpress.uz/Snake.3-4/
- https://dexxpress.uz/Snake.1.1-4/

Ограничение этой среды: сетевой доступ из контейнера к бинарным файлам dexxpress.uz недоступен, поэтому я не мог здесь скачать все фотографии и сравнить готовые страницы в реальном браузере. Скрипт должен запускаться на вашем компьютере с обычным доступом к сайту. Он сохраняет исходную разметку и исходный порядок подключений ресурсов, а не подменяет фотографии случайными аналогами.
